# KUMARIM（公開版）

ブラウザで遊べる 3D サバイバルゲームです（開発版 v114.5）。

- 遊ぶ：このリポジトリの GitHub Pages のページ（`https://ユーザー名.github.io/リポジトリ名/`）を開きます。
- 必要なもの：パソコンの Chrome / Edge など、WebGL2 が使えるブラウザ（スマートフォンは対象外です）。
- 最初の読み込みに 1〜3 分ほどかかります（約140MB）。2回目からは速くなります。
- 操作：WASD 移動・マウスで見回す・左クリックで道具を使う・E で拾う・Tab でつくる・右クリックで食べる。

素材のクレジットは `ATTRIBUTION-environment.txt` と `audio/` の中の説明にあります。
